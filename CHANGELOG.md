# Changelog

All notable changes to this project will be documented here. The project uses
pre-release versions while the Alpha contracts and operational gates are still
being validated.

## [0.1.0a1] — release candidate documentation (unreleased)

This entry describes the planned GitHub Release only. No tag, GitHub Release,
or PyPI publication was created by S06.

### Added

- Apache-2.0 licensing and minimum contribution, conduct, and security policy.
- English public release documentation for installation, MCP, SDK, CLI,
  support, known issues, and roadmap.
- A PostgreSQL + pgvector quickstart and an explicitly labelled file-backed
  demo harness.
- Versioned MCP stdio, export/import, owner-scope, and privacy limitations in
  the release documentation.

### Not yet a release claim

- Retrieval quality for `hash/v1` has not been measured in the available S04
  handoff evidence.
- Backup/restore/delete-retention readiness has not been demonstrated in the
  available S05 handoff evidence.
- No hosted authentication, tenant isolation, E2EE, zero knowledge, or scale
  benchmark is provided.
